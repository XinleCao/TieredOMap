# Experiment Guide

This guide gives the commands used to exercise the TieredOMap artifact. The
small commands are intended for a reviewer smoke test. The full paper-scale
commands require larger machines.

## Build

```bash
mkdir -p build
cd build
cmake .. -DCMAKE_BUILD_TYPE=Release
cmake --build . -j
```

## Unit Tests

```bash
ctest --output-on-failure
```

## Local Smoke Test

```bash
./bench_paper --exp=backend_cmp --Q=50 --max_logN=16 --outdir=../smoke-results
./bench_paper --exp=bandwidth --Q=50 --max_logN=16 --outdir=../smoke-results
./bench_paper --exp=skewness --Q=50 --outdir=../smoke-results
```

## Client/Server Experiments

Start the server:

```bash
bash scripts/run_server.sh 12345
```

Run the benchmark from the client:

```bash
bash scripts/run_paper_experiments.sh 20 500 SERVER_IP 12345
```

For the paper-scale run, increase the maximum database size:

```bash
bash scripts/run_paper_experiments.sh 24 500 SERVER_IP 12345
```

The output directory contains CSV files such as `paper_wan.csv`,
`per_backend.csv`, `bandwidth_vs_N.csv`, and `skewness.csv`.

## Dynamic Maintenance Simulation

The dynamic-maintenance figure data are generated by a Python simulator because
the paper studies the long-run hot-set adaptation process.

```bash
python scripts/sim_dynamic.py regenerated-dynamic
```

The script writes:

- `dynamic.csv`
- `drift.csv`
- `dynamic_N20.csv`
- `drift_N20.csv`

For a quick local smoke test, run:

```bash
python scripts/sim_dynamic.py smoke-dynamic --smoke
```

## Derived Skewness and Hot-Set-Size Coordinates

```bash
python scripts/compute_skewness_hotsize.py artifact-data/profile/profile.csv
```

The script prints the coordinates used for the skewness and hot-set-size plots.

## TEE Experiments

TEE experiments require an SGX-capable machine and Gramine. The manifest
templates included in the repository are examples and usually need local path
adjustment.

Use the generic template:

```bash
bash scripts/run_tee_e2e_template.sh
```

Set the following environment variables before running it:

- `TEE_HOST`
- `TEE_USER`
- `TEE_KEY`
- `TEE_REPO`
- `PORT`

The paper-facing TEE CSV files are under `artifact-data/tee/`.
